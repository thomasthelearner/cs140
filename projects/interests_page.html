About 'Links'

A relative link is a hyperlink that points to a file or resource relative to the current page's location. For example, <a href="hero_page.html">Hero</a> is a relative link to the hero_page.html file in the same directory.

Ex: Click here to visit my profile page.

An absolute link is a hyperlink that points to a file or resource using the full URL, regardless of the current page's location. For example, <a href="https://www.google.com">Google</a> is an absolute link to the specified website.

Ex: Click here to visit my ML's favorite curriculum website.
