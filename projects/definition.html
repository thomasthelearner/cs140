Internet

Internet is the global network that connects all of the computers and devices together. It allows them to communicate and share information across the world.

Web

The web or World Wide Web is a massive information system based on the Internet that allows the documents and other web resources to be accessed and shared globally through the browsers. The web has some crucial components such as web browsers, web servers, HTML, CSS, JavaScript, etc., which are well known.

How are the Internet and Web different?

The Internet is infrastructure, which technically is a foundation or the core of the web, while the web is a collection of interconnected documents and resources in order to display information visually to the users.

ASCII and Unicode

ASCII stands for American Standard Code, while Unicode stands for Universal Character Set. ASCII is a set of American alpha-numeric (0-9, A-Z, a-z) characters that are used to represent text in devices. Unicode, on the other hand, is a more comprehensive character set that includes characters from many different languages and writing systems.

What is UTF-8?

UTF-8 is a character encoding that supports all Unicode characters and is the most widely used encoding on the web nowadays. It basically will translate the characters into set of binary code to the device in order to display them correctly on screens.

URL

URL is an acronym for Uniform Resource Location, which is an unique address that contains the domain name of a site as well as other information, including the protocol and the path that used by the web browsers to access to web resources such as HTML, CSS, and JavaScript files.

Domain Name

Domain name is a string of text that maps to an alphanumeric IP address, or the user's website address. For example, Google's domain is google.com.

HTTP

HTTP stands for HyperText Transfer Protocol. It is the foundation of web communication, allowing browsers to load web pages using hyperlinks. For example, http://www.google.com

HTTPS

HTTPS stands for HyperText Transfer Protocol Secure. It is just a secure version of HTTP, more protected than HTTP, that uses encryption to protect the data being transmitted between the browser and the server. For example, https://www.google.com

IP Address

IP address is a unique Internet Protocol address. It is a numerical label, such as 192.168.1.1, that is assigned to a device connected to a computer network that uses the Internet Protocol for communication.

DNS

DNS is an acrosym for Domain Name System. It is a system that translates domain names into IP addresses.

W3C Recommendations

W3C Recommendations is a web standard created by World Wide Web Consortium that creates the rules and standards for WWW, while WWW again is the actual system of interlinked web pages and resources.

XML, XHTML, HTML, HTML5

These are different versions of markup languages. Each of them has their own purpose, syntax, and features. Currently, HTML5 is the most widely common used markup language on the web.
