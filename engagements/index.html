Welcome to CS 140!

    1. Internet is a system that the computers connect to each other. The wire that usually be used to connect the computers is in the bottom of the ocean.
    2. Web is a system that computers communicate with each other through the internet. The web is created by Tim Berners_Lee after the internet was created.
    3. Part of internet is the 4 numbers. For example, 127.0.0.1 is the IP address. Each computer has the unique IP address.
    4. Git and GitHub is the way to share the code to other people. Git is the tool working on the local computer by committing the code. Then, you push the code to GitHub. Then, if somebody wants to see your code, they will pull the code from GitHub to their local computer. GitHub is owned by Microsoft. So, when we push the code to GitHub, we will have the URL link to share with other people.
    5. !DOCTYPE tag is the version of HTML. It declared the HTML version to the browser. "<>" is the tag that is used to create the HTML document.
