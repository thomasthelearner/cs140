Q&A

  1. The form tag has an "action" attribute. What does it do? (It specifies where to send the form data when the form is submitted.)
  2. The form tag has a "method" attribute. What does it do? (It specifies the HTTP method to use when submitting the form.)
  3. What is the difference between a "POST" and a "GET"? (POST is used to send data to the server, while GET is used to retrieve data from the server.)
  4. How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button. (We use the "value" attribute to set a pre-set value, while a placeholder is just a hint that disappears when the user starts typing. With the text box, we use the "value" attribute to set the initial text. With the textarea, we use the "value" attribute to set the initial text. With the select box, we use the "value" attribute to set the selected option. With the checkbox, we use the "checked" attribute to set it as checked. With the radio button, we use the "checked" attribute to set it as checked.)
  5. List all the form controls that HTML5 added. Which ones did you put in your form? (HTML5 added several new form controls, including date, time, email, url, search, and range inputs. I put the email input in my form.)
  6. What are different ways to style your form? (You can use CSS to style your form, including setting colors, fonts, and layout.)
  7. Why does the professor like to use flex? (Flexbox is a powerful layout tool that makes it easy to create responsive designs.)
  8. What are some best practices for creating a good user experience with forms? (Some best practices include using clear labels, providing helpful error messages, and ensuring the form is easy to navigate.)
  9. What makes for a good mobile form? (A good mobile form should be easy to use on a small screen, with appropriately sized touch targets and a layout that adapts to different screen sizes.)
