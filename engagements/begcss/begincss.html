CSS

  1. Q1: Inline CSS is applied directly within an HTML element using the style attribute. Embedded CSS is defined within a <style> tag in the head section of the HTML document. Lastly, external CSS is defined in a separate .css file and linked to the HTML document using the <link> tag.
  2. Q2: We should use external CSS for better maintainability and separation of concerns. Also, it allows for consistent styling across multiple pages and easier updates.
  3. Q3: A selector is a pattern used to select the elements you want to style in CSS.
