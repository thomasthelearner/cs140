  1. What is normal flow in HTML? Normal flow is the default way that elements are laid out in a web page. Usually, block boxes stack from top to bottom, and inline content runs from left to right inside them.
  2. What does float do? Why do you need to clear the float? Float is used to position an element to the left or right of its container. You need to clear the float to prevent non-relevant elements from overlapping with the floated element.
  3. What do absolute, fixed, and relative do? Relative positions is when an element is positioned relative to its normal position, used for moving or shifting elements. Absolute positions is when an element is positioned as overtop of any other element. Fixed positions is when we scroll the page and the element stays in the same place.
