  1. List out the different ways to select an item: Tag name, decendent, a bunch of other stuff, id, class
  2. What is the difference between an ID and a Class?: ID is unique, Class can be reused and we can have more than one class in one element
  3. What is the difference between a SPAN tag and a DIV tag?: SPAN is inline (no line break), DIV is block. Both of them are used to group content.
  4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?: Frankly, they don't have much difference in terms of functionality, but HEADER, MAIN, and FOOTER are semantic elements that describe the structure of the page.
