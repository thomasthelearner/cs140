Q&A

  1. What is JavaScript? How did it get its name? (Originally called LiveScript, but renamed to JavaScript to capitalize on the popularity of Java)
  2. What are the two ways you can run JavaScript? (In the browser and in Node.js)
  3. What is jQuery? Is it still popular today? (jQuery is a JavaScript library—a collection of ready-made tools that makes tasks like changing HTML, responding to clicks, and adding animations easier. It uses JavaScript; it is not a separate programming language. And it's still widely used nowadays.)
  4. What is the most popular front-end js library today? (React is the most popular front-end JavaScript library by developer usage in Stack Overflow’s 2026 survey, with about 42% of respondents using it.)
  5. How does your code prevent the form from being submitted? Why do we need to prevent it? (event.preventDefault() stops the browser’s normal form submission. Normally, submitting a form sends its data to the form’s destination and can load another page. Preventing that lets your JavaScript display feedback or send the data without leaving the current page. It does not send or save the data by itself.)
  6. What is AJAX? (AJAX stands for Asynchronous JavaScript and XML. It is a technique for creating interactive web applications by allowing the browser to send and receive data from a server asynchronously, without reloading the page.)
  7. Why do you put your JS Code in a separate file? (Putting JavaScript in a separate file helps to keep the HTML code clean and maintainable. It also allows for code reusability and better organization of the application.)
  8. How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error? (You can use the browser's DevTools to set breakpoints, step through code, and inspect variables. The console will show error messages with line numbers where the error occurred.)
  9. Do your form and fields have the same ids that your JavaScript uses? Does the Console show any errors? List your ids, and fix any errors before you submit. (Yes and I don't have any errors. My ids list are: myForm, personname, username, email, bdate, password)
