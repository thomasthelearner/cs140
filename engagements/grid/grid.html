  1. According to the instructor, what is the main difference between CSS Grid and CSS Flex? CSS Grid is a two-dimensional layout system (handling rows and columns simultaneously), whereas CSS Flexbox is a one-dimensional layout system (handling either a single row or a single column at a time).
  2. Who decides where a child goes on the page: the child or its parent? Explain using your three-column layout. The parent decides where a child goes on the page. Because the parent is responsible for defining the layout and positioning of its children.
