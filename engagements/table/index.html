  1. When do you use a table? We will use tables to display data in a structured format.
  2. When do you not use a table? When the data is not suitable for a tabular format or when a simple list is more appropriate.
  3. When do you need to do extra work for table accessibility? When the table is complex or contains a lot of data, it may require additional work to ensure it is accessible to all users, including those with disabilities.
  4. Which question you asked AI today helped you learn the most, and why? The question about the accessibility of tables. Because it helped me understand the importance of making tables accessible to all users, and how to label them properly and all.
  5. Did AI ever try to give you more than you asked for, like writing your code? What did you do? Yes, sometimes AI provides more information than what is explicitly requested. In such cases, I try to focus on the relevant information and disregard the extra details.
  6. Why don't we use the border attribute? Because CSS provides more control over the appearance of tables and is more maintainable.
  7. What is the easiest way to color every other row a different color? The easiest way is to use the :nth-child() pseudo-class in CSS.
  8. What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select. The value in the parentheses of a structural pseudo-class represents the position of the element within its parent. For example, :nth-child(2) would select the second child element of its parent.
